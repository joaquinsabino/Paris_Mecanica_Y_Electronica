# Paris Mecánica y Electrónica

## Descripción
Sitio web de un taller de mecánica y electrónica
automotriz.

El proyecto fue migrado de HTML a PHP,
implementando modularización mediante includes
y renderizado del lado del servidor (SSR).

## Prototipo de Figma
https://www.figma.com/design/lIinKAIWm4DavELXRoVk7q/Pagina_Sabino?t=NbF9ZAQGe9EvPKzR-0

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- PHP 8
- XAMPP
- Git y GitHub

## Instalación y ejecución

1. Descargar o clonar el repositorio.
2. Copiar la carpeta en htdocs de XAMPP.
3. Iniciar Apache.
4. Abrir http://localhost/TP_HTML/

## Modularización
Se utilizaron archivos PHP reutilizables:

- includes/header.php
- includes/nav.php
- includes/footer.php

## Variables de entorno
Se utiliza .env para almacenar
la configuración del proyecto.

El archivo .env.example permite
conocer las variables necesarias.
